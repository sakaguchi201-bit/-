# ホームページ

HTML / CSS / JavaScript だけで作ったシンプルなホームページです。ビルド不要で、`index.html` をブラウザで開くだけで表示できます。

## ファイル構成

- `index.html` — ページの内容（文章はここを編集）
- `style.css` — デザイン（色は先頭の `:root` で変更）
- `script.js` — スマホメニューとお問い合わせフォーム

## 公開方法（GitHub Pages）

1. GitHub のリポジトリで **Settings → Pages** を開く
2. **Source** で公開したいブランチとフォルダ `/ (root)` を選んで保存
3. 数分後に表示される URL でサイトが公開されます
